# FPT Cost Brain - Project Clusters

Project clusters categorize R&D requests by their primary focus area.

## Cluster Categories

### New Engine HW
Nuovo componente hardware del motore, nuova turbo, etc..

### New ECM
New Engine Control Module, cambio chip, porting ECU, etc…

### New ATS
Nuovo componente hardware after-treatment system, nuovi sensori, etc…

### New SW
Nuovo SW, nuovo dataset

### Performance - Power/Torque
Miglioramento prestazioni

### New model
Nuovo veicolo

### New market
Nuovo mercato

### Regulation
Cambio normativo, cambio emissivo legato a un nuovo mercato

### OBD
On-board-diagnosis change

### Service interval change
Cambio maintenance interval (e.g. nuovo HW fuel filter che porta da 500h a 1000h la service)

### Self-diagnosis
Routine di service

### E/E architecture
Nuova architettura da 1-box a 2-box

### Innovation
None

### Digital Transformation
Change in E/E architecture (1box, 2box), new CAN from 250k to 500kbps, new Cluster (phoenix, VIS, etc…)

### Local fuel compatibility
Richiesta di compatibilita' con fuel locale per nuovi mercati (e.g. Cile, Colombia)

### New fuel
e.g. B20 fuel, ethanol

### Sustainability
Include le richieste che mirano a rendere i prodotti più sostenibili dal punto di vista ambientale, come l'uso di materiali riciclati o la riduzione delle emissioni.

### Cost Reduction
Include le richieste che mirano a ridurre i costi di produzione o di esercizio.

### Quality Improvement
Comprende le richieste volte a migliorare la qualità del prodotto, riducendo i difetti o aumentando l'affidabilità.

### Safety Enhancements
Comprende le richieste volte a migliorare la sicurezza del prodotto, sia per gli utenti finali che per gli operatori.
